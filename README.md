# Taylor Morrison Home

Taylor Morrison Home Corporation (NYSE: TMHC) is a leading national homebuilder and developer recognized as America's Most Trusted Home Builder for eleven consecutive years. Taylor Morrison designs and constructs single-family homes, communities, and lifestyle developments across the US, pioneering the industry's first fully digital home purchase and reservation platform.

**Website:** [https://www.taylormorrison.com/](https://www.taylormorrison.com/)
**Investor Relations:** [https://investors.taylormorrison.com/](https://investors.taylormorrison.com/)
**Newsroom:** [https://newsroom.taylormorrison.com/](https://newsroom.taylormorrison.com/)
**Mortgage:** [https://www.taylormorrisonfunding.com/](https://www.taylormorrisonfunding.com/)

## APIs

### Taylor Morrison Home Search API
Search new home communities, floor plans, lots, and available homes. Powers the digital homebuying experience including the industry-first to-be-built online reservation system.

- **Base URL:** https://www.taylormorrison.com/api
- **Auth:** API Key
- **Docs:** [https://www.taylormorrison.com/](https://www.taylormorrison.com/)

### Taylor Morrison Home Funding API
Mortgage origination integrated with the homebuying process, with Fannie Mae Day 1 Certainty for automated income and asset verification.

- **Docs:** [https://www.taylormorrisonfunding.com/](https://www.taylormorrisonfunding.com/)

### Taylor Morrison Design Studio API
Digital design studio for floor plan personalization — structural options, exterior selections, flooring, cabinets, and finish choices.

- **Docs:** [https://www.taylormorrison.com/design-studio](https://www.taylormorrison.com/design-studio)
